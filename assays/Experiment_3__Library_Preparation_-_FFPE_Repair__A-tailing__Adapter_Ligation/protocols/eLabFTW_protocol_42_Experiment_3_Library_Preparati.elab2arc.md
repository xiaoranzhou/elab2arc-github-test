Goal:
=====

Library preparation using NEBNext FFPE DNA Repair Mix
=====================================================

Procedure:
==========

**Steps performed:**

*   FFPE DNA repair [Methode - NEBNext FFPE DNA Repair Mix](https://elab.dataplan.top/experiments.php?mode=view&id=56)
    
*   End-repair and A-tailing
    
*   Ligation of Illumina-compatible adapters (NEBNext Multiplex Oligos)  
    **Input DNA:** 200 ng per sample ( [Assay - Experiment 2: DNA Extraction](https://elab.dataplan.top/experiments.php?mode=view&id=19))  
    **Clean-up:** AMPure XP beads (1.8x)  
    **QC:** Bioanalyzer traces (average library size ~420 bp)  
    **Output:** Indexed libraries for sequencing  
    **Storage:** -20 °C  
    **Notes:** No signs of adapter dimers; libraries passed QC for sequencing.
